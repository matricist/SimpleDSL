# Still Morning Letter 작곡 후 메모

## 기준

요청은 완전한 뉴에이지 피아노 곡이었다. 특정 작곡가나 특정 곡의 선율을 따라 하기보다는, 서정적인 솔로 피아노 뉴에이지에서 자주 쓰이는 넓은 특징을 사용했다.

목표 감정은 다음과 같다.

- 조용함
- 따뜻함
- 약간의 그리움
- 어렵지 않은 선율
- 반복되는 왼손 아르페지오
- 과하게 극적이지 않은 클라이맥스
- 중반 이후의 작은 기교와 변칙
- 앞부분부터 너무 정박으로만 흐르지 않는 작은 3연음
- 코드 심볼이 악보 위에 보이는 형태
- 기존보다 조금 높은 중급 난이도

## 길이 계산

- BPM: 64q
- 박자: 4/4
- 전체 길이: 48마디

64 BPM에서 4/4 한 마디는 3.75초다. 48마디는 약 180초, 즉 3분 정도다.

## 구조

| 섹션 | 마디 | 역할 |
| --- | --- | --- |
| Intro | 1-4 | 주제의 정서와 왼손 패턴 제시 |
| A | 5-16 | 첫 번째 선율 진술 |
| A' | 17-28 | 같은 선율권을 조금 더 풍성하게 반복 |
| B | 29-40 | 중간부 상승과 감정 확장 |
| Return | 41-48 | 단순한 회귀와 C major 종지 |

## 작곡 아이디어

### 왼손

왼손은 처음에는 8분음표 분산화음으로 움직인다. 뉴에이지 피아노에서 안정감을 주는 기본 장치다. 다만 수정 버전에서는 A'와 B 섹션에 일부 4분음표 베이스를 섞었다. 이렇게 하면 왼손이 계속 같은 모양으로만 흐르지 않고, 문장마다 살짝 숨을 쉰다.

처음 버전은 왼손이 `C3-G3-E4`처럼 10도 가까이 벌어지는 경우가 많아서 실제 연주 난도가 높았다. 지금 버전은 `C3-G3-E3-G3`처럼 같은 화성을 더 가까운 위치로 접었다. 울림은 조금 덜 넓어지지만, 한 손 안에서 훨씬 자연스럽게 굴러간다.

패턴은 다음처럼 단순하게 유지했다.

```text
C3-2;;G3-2;;E3-2;;G3-2;;C3-2;;G3-2;;E3-2;;G3-2;;
```

이런 패턴은 멜로디가 복잡하지 않아도 곡이 계속 흐르는 느낌을 준다.

### 오른손

오른손은 4분음표와 8분음표 중심으로 노래하게 만들었다. 이후 수정에서 16분음표 pickup과 passing motion을 추가했다. 뉴에이지의 단순함은 유지하되, 중반 이후가 너무 평평하게 들리지 않도록 작은 물결을 넣은 것이다.

추가 수정에서는 곡의 앞단에도 3연음과 엇박 진입을 넣었다. 다만 한 마디 안에 둘을 동시에 넣으면 리듬 정보가 너무 많아져서 어색하게 들렸다. 그래서 현재 버전은 1, 3, 5, 7마디를 3연음 중심으로, 2, 4, 6, 8마디를 엇박 중심으로 분리했다.

예:

```text
G5-1B5-1;A5-1C6-1;C6-4E6-4
```

이런 짧은 연결구는 선율을 과하게 화려하게 만들지 않으면서도 다음 화음으로 미끄러져 들어가는 느낌을 준다.

3연음 예:

```text
T3[G5,A5,G5]-4
```

이 표기는 한 박 안에서 G-A-G가 3연음으로 지나가는 장식적인 연결구다.

엇박 예:

```text
;F5-3;;;G5-1;B5-4
```

이 표기는 첫 16분음표를 비우고 들어가므로 선율이 살짝 뒤에서 밀려 나오는 느낌을 준다. 단, 같은 마디에는 3연음을 넣지 않았다.

### 코드 심볼

코드 심볼은 이제 RH 선율 안에 직접 붙이지 않고, 별도의 `@Chord` 섹션에 둔다. 예를 들어 `C | G | Am | F`처럼 쓰면 각 마디 첫 슬롯에 코드가 배치된다. 이 표기는 소리 자체를 바꾸지는 않고, MusicXML에서 `<harmony>`로 나가서 악보 위에 코드명이 보이게 한다.

### 화성

화성은 의도적으로 단순하게 잡았다.

- C
- G
- Am
- F
- C/E
- Dm
- Em

복잡한 재즈 보이싱보다는, 익숙하고 투명한 진행을 사용했다. 뉴에이지에서는 이 단순함이 오히려 장점이 된다.

### 클라이맥스

B 섹션은 완전히 폭발하지 않고 살짝 들어 올리는 방식으로 썼다. 높은 음역의 2음 화음이 늘어나고, 16분음표 연결구가 많아진다. 이번 수정에서는 일부 오른손 dyad를 triad로 바꾸고, 왼손 첫 박에도 5도 dyad를 섞었다. 그래서 악보가 너무 쉬워 보이지 않되, 손이 과하게 벌어지는 난이도 상승은 피했다.

## 수정하면서 추가한 변칙

- A'부터 오른손에 16분음표 pickup을 넣었다.
- 왼손은 일부 마디에서 첫 박을 4분음표로 넓게 두어 호흡을 만들었다.
- B 섹션은 높은 2음 화음과 짧은 passing motion을 늘렸다.
- Return에서는 기교를 다시 줄여 처음의 평온함으로 돌아오게 했다.
- Intro와 A 초반에 3연음 turn을 넣어 앞단의 심심함을 줄였다.
- 일부 멜로디는 첫 슬롯을 비우고 들어가게 해서 약한 엇박 느낌을 만들었다.
- 3연음과 엇박이 같은 마디에서 동시에 나오지 않도록 앞 8마디를 다시 나눴다.
- 왼손은 10도권 분산화음을 줄이고, 5도-6도 안쪽의 가까운 패턴으로 접었다.
- 코드 심볼은 RH에서 분리해 `@Chord` 섹션으로 옮겼다.
- A'와 B 섹션의 오른손에 일부 3화음을 추가했다.
- B 섹션 왼손 첫 박에 5도 dyad를 추가해 난이도와 울림을 조금 올렸다.

## 왜 이렇게 만들었나

이 곡은 "기억을 담은 편지" 같은 느낌을 목표로 했다. 멜로디가 크게 울부짖기보다는, 같은 말을 여러 번 조용히 되뇌는 쪽이다.

그래서 선율도 너무 멀리 튀지 않고, C major와 A minor 주변에서 움직이게 했다. 마지막은 C major 전체화음으로 확실히 닫아서, 듣고 난 뒤 불안하지 않게 만들었다.

## 나중에 손보면 좋은 점

- 실제 페달 정보가 DSL에 들어가면 뉴에이지 느낌이 훨씬 좋아질 것이다.
- 다이내믹 표시가 생기면 A는 `p`, B는 `mp-mf`, 마지막은 다시 `p`로 줄 수 있다.
- 왼손 패턴이 아직 비슷하게 반복되는 부분이 있으므로, 나중에는 일부 마디에 옥타브 베이스나 쉼을 더 넣어 호흡을 만들 수 있다.
- MIDI 렌더링이 생기면 velocity를 낮게 잡고, 후반부만 살짝 올리는 방식이 잘 어울린다.
