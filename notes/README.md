# Development Notes

이 폴더는 Music DSL 프로젝트에서 앞으로 손봐야 할 방향을 모아두는 작업 메모입니다.

## 문서 목록

- [01-dsl-roadmap.md](01-dsl-roadmap.md): DSL 문법, 검증, VS Code 확장 기능 아이디어
- [02-sample-instructions.md](02-sample-instructions.md): 샘플 작곡 지시사항을 더 체계화하는 방향
- [03-pipeline-roadmap.md](03-pipeline-roadmap.md): DSL에서 MusicXML/SVG 이후의 출력과 빌드 파이프라인 확장

## 운영 원칙

- 아이디어와 구현 요구사항을 분리해서 적는다.
- "나중에 좋을 것"과 "지금 없으면 품질이 흔들리는 것"을 구분한다.
- DSL 자체의 문제인지, 작곡 지시사항의 문제인지, 변환 파이프라인의 문제인지 분류한다.
- 사람이 쓰기 쉬운 형식과 AI가 생성하기 쉬운 형식을 동시에 고려한다.
